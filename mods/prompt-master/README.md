# Prompt Master

Rewrites the rough prompt in your prompt box into a clearer, more specific one before you send it.

- Click **✨ Prompt Master** in the band just above the prompt box (terminal and desktop), or run `/prompt-master` anywhere.
- `/prompt-master <text>` rewrites the given text instead of the draft.
- **Undo** (or `/prompt-master undo`) puts your original draft back.

Nothing is sent automatically: review the rewrite, then press Enter.
